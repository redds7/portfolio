# redds. portfolio

Портфолио веб-разработчика и три демонстрационных сайта. Статические HTML, CSS и JavaScript без сборщиков и зависимостей.

## Структура

- `index.html` главная страница портфолио
- `zerno/` лендинг кофейни
- `yurist/` сайт-визитка юриста
- `fotograf/` портфолио фотографа

У каждого демо свой `index.html`, `style.css`, `main.js` и папка `assets/images` с векторными иллюстрациями.

## Запуск

Откройте `index.html` в браузере. Для корректной работы всех ссылок удобнее локальный сервер:

```
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

С главной страницы каждое демо можно посмотреть в предпросмотре или открыть в отдельной вкладке через ссылку «Перейти на сайт».

## Публикация

Проект подходит для GitHub Pages: включите публикацию из ветки `main`, папка `docs` не нужна, корень репозитория является источником.

Все контакты, адреса, цены и изображения в демо вымышлены и нужны только для демонстрации.
